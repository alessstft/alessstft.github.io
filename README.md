# Портфолио — Бацаценко Алеся Андреевна

## Структура

```
index.html        — разметка страницы (заголовок, блоки, подвал)
css/style.css     — оформление: цвета, шрифты, плёнка, анимация проявки
js/config.js      — контакты, стек технологий, проекты и ссылки на GitHub
js/roles.js       — профессии: тексты, вкладки, какое фото и какая его часть
js/main.js        — логика: сборка плёнки, переключение кадров и темы
img/              — фотографии
```

## Частые правки

- **Контакты и GitHub** — `js/config.js`, пустая строка `''` скрывает пункт.
- **Новый проект** — `js/config.js`, скопируйте блок `{ ... }` в `projects`.
- **Тексты профессий** — `js/roles.js`.
- **Заменить фото** — положите новый файл в `img/` с тем же именем
  (например `img/teacher.jpg`) или поменяйте путь в `css/style.css` (классы `.ph-...`).
- **Сдвинуть фото в кадре** — поле `pos` в `js/roles.js`.
- **Цвета** — переменные в начале `css/style.css` (отдельно для светлой и тёмной темы).
- **Имя и текст на первом экране** — `index.html`.

## Размещение

GitHub Pages: загрузите содержимое папки в репозиторий `ваш-ник.github.io`
(так, чтобы `index.html` лежал в корне) — сайт откроется по `https://ваш-ник.github.io`.
Или перетащите всю папку на https://app.netlify.com/drop.
